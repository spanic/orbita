# Таблица триажа безопасности

Выполненные сканирования: Gitleaks (секреты), Semgrep `auto`, `p/owasp-top-ten`, `p/java`, `p/security-audit`

| ID      | Инструмент                          | Проблема                                                                                                              | Приоритет | TP/FP | Риск                                                                                                                                                                   | Решение                                                                                                                                        |
| ------- | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------- | --------- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| SEC-001 | Semgrep (`auto`, `p/owasp-top-ten`) | `orders-service/Dockerfile:15` — контейнер запускается от `root` (отсутствует инструкция `USER`)                      | Средний   | TP    | При компрометации JVM-процесса атакующий получает root внутри контейнера, что упрощает побег из контейнера                                                             | Добавить непривилегированного пользователя перед `ENTRYPOINT`: `RUN addgroup -S app && adduser -S app -G app` + `USER app`                     |
| SEC-002 | Semgrep (`auto`, `p/owasp-top-ten`) | `payments-service/Dockerfile:15` — контейнер запускается от `root` (отсутствует инструкция `USER`)                    | Средний   | TP    | Аналогично SEC-001; повышенный impact, так как payments-service обрабатывает финансовые данные                                                                         | Аналогично SEC-001                                                                                                                             |
| SEC-003 | Semgrep (`p/owasp-top-ten`)         | `gateway/proxy-common.conf:1` — `$host` передаётся через `proxy_set_header Host` и может быть подконтролен атакующему | Низкий    | FP*   | В типовой конфигурации обратного прокси `$host` нормализуется Nginx и не является прямым вектором атаки; риск актуален только при отсутствии allowlist в `server_name` | Добавить явный `server_name` в блок `server`, либо заменить `$host` на hardcoded hostname, если бэкенд не требует оригинального заголовка Host |

> \* SEC-003 — **условный FP**: правило срабатывает корректно по политике, но реальная эксплуатируемость зависит от конфигурации блока `server` в Nginx. Отметить как TP, если allowlist в `server_name` не настроен.
